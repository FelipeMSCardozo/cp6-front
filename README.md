# Portfólio do Felipe

Fiz esta página para juntar alguns trabalhos de aula e ideias que estou usando para praticar desenvolvimento web.

## Como abrir

1. Extraia a pasta.
2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada. A página usa HTML e CSS e não depende de bibliotecas externas.

## O que tem aqui

- Uma apresentação rápida sobre mim
- Os assuntos que estou estudando
- Seis projetos e ideias para praticar
- Uma seção de contato com meu LinkedIn

## Projetos

- **Consulta de CEP:** consultar um endereço usando um CEP.
- **MeuPreço:** uma ideia de ferramenta para calcular o preço de venda de produtos; ainda está em andamento.
- **Agenda de Serviços:** organizar os horários de pequenos negócios.
- **Estoque Fácil:** acompanhar os produtos de uma loja pequena.
- **Rotina de Estudos:** anotar tarefas e prazos da semana.
- **Controle de Gastos:** registrar o dinheiro que entra e as despesas do mês.

Alguns projetos ainda são ideias ou estão em andamento. Deixei isso indicado na página para não parecer que tudo já está pronto.
